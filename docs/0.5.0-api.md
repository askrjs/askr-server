# 0.5 API inventory and migration

This preparation cut reviews all **214 exported name/path pairs** in the 0.4 baseline. The candidate has **87 contracts**, each with one canonical import path. The nine functional entry points and `package.json` export remain. The package stays at its current version until coordinated release preparation.

## Migration

- Import `createServerApp` and application/adapter types from `@askrjs/server`; import `createRouter`, `Router`, and `ApiRouteOptions` from `@askrjs/server/router`.
- Import standalone `json`, `text`, `redirect`, `problem`, cookie helpers, and event streams from `@askrjs/server/http`. Use handler context methods such as `ctx.created()` or `ctx.notFound()` for status responses. Outside a handler, use `json(value, { status: 201 })`, `problem(status, detail)`, or a native `Response`.
- Replace `ctx.bad()` with `ctx.badRequest()` and `ctx.serverError()` with `ctx.internalServerError()`.
- Replace `defineRoutes(...)` route arrays with `createRouter().get(...).post(...).ws(...)`. Literal route paths still infer handler parameter names.
- Import `createCspNonce` and `CspNonceProvider` from `@askrjs/server/middleware`.
- Import `schema`, `Schema`, and `InferSchema` directly from `@askrjs/schema`.
- Use `ctx.bind()` and request-size options rather than the private body readers. Body errors produce the documented HTTP Problem response through binding.
- Use `csrf` middleware for token verification. Mount MCP discovery through `registerMcpRoutes` metadata options.
- Derive supporting types from their owning options, handlers, or return values as listed below. These shapes remain accessible through supported contracts; their redundant named exports are removed.

```ts
import { createServerApp, type ServerAppOptions } from "@askrjs/server";
import { createRouter } from "@askrjs/server/router";
import { json } from "@askrjs/server/http";
import { schema } from "@askrjs/schema";

type DenialHandler = NonNullable<ServerAppOptions["onAccessDenied"]>;
const router = createRouter().get("/users/{id}", (ctx) => ctx.ok({ id: ctx.params.id }));
const app = createServerApp(router);
const standalone = json({ ready: true }, { status: 202 });
const User = schema.object({ id: schema.string() });
```

## Adapter testing ownership

Keep dedicated Server/testing runner and diagnostic class because Node adapter authors qualify Server transport guarantees here. Remove supporting aliases, derive them from runner/class. Production root does not import the test runner; generic injection remains Testing-owned.

The runner stays under the dedicated testing entry point and is absent from the production root. Generic request injection belongs to `@askrjs/testing`. The runner is consumed by the Node adapter to verify actual streaming cancellation and incomplete-request expiry.
